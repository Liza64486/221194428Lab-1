GeoScan Attendance Pro

Proposed Team Project

GeoScan Attendance Pro is a web-based smart attendance system designed to improve the accuracy and reliability
of student attendance records.

The system aims to reduce attendance fraud, especially when students sign attendance on behalf of absent students.
It uses technology to help lectures record attendance more securely.

Project Objectives

  • To improve the accuracy of attendance records.
  • To reduce attendance fraud.
  • To allow lectures to manage student attendance.
  • To allow students to mark their attendance electronically.
  • To improve the security and reliability of attendance records.

How the System Works

  1. The lecturer starts an attendance session.
  2. The system generates a QR code for the class.
  3. Students log into the system and scan the QR code.
  4. The system checks the student's location.
  5. Attendance is recorded when the requirements are satisfied.

Main Features

  • Student login
  • Lecture dashboard
  • Administrator dashboard
  • Dynamic QR code attendance
  • GPS/location verification
  • Attendance records
